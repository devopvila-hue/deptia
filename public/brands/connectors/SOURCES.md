# Connector brand assets

Unmodified SVG brand assets downloaded from Simple Icons 11.15.0:
https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/{slug}.svg
Project: https://github.com/simple-icons/simple-icons/tree/11.15.0

These are existing brand paths, not generated illustrations, letter substitutes or hand-drawn approximations. The carousel applies each brand's official color to the supplied paths while keeping the white logo tile consistent in both site themes.

The active list is in src/data/home-connectors.ts and contains sixteen unique brands. Pipedrive uses a local mark because it is not included in the referenced Simple Icons release.
